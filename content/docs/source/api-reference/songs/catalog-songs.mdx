---
title: Get Catalog Songs
openapi: get /api/catalogs/songs
---

<Note>
  This endpoint supports pagination. The Catalog Songs API also supports POST for adding songs and DELETE for removing songs. See the [Add Catalog Songs](/api-reference/songs/catalog-songs-add) and [Remove Catalog Songs](/api-reference/songs/catalog-songs-delete) endpoints.
</Note>

A successful query with no matching songs returns HTTP `200`, an empty `songs`
array, and `pagination.total_count: 0`. This also applies to an accessible catalog
with no songs. An empty result is not a `404` response.

Use a nonempty `artistName` to request songs with a matching artist name. Omit the filter to
include songs without a linked artist. Filtering applies before pagination and
the total count; a client can use a zero count to decide whether to retry without
the artist filter.

Missing or inaccessible catalogs return `403`. A server or database failure
returns `500` with `status: "error"` and `error: "Internal server error"`.
