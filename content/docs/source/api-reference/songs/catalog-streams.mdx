## Date range and coverage

Set `days` to an integer from 1 to 366 days. For example, use `days=90` for a 90-day comparison period. `since` is the inclusive start of the current period; the previous period has the same length and immediately precedes it. End dates are exclusive.

A supported date range does not prove complete measurements or historical backfill. Inspect each recording's coverage and missing dates before using growth comparisons, and continue through pages while `pagination.has_more` is true. Missing measurements suppress growth; they do not establish zero streams.

The catalog playcount-history operation has a separate 31-day maximum. It reports saved Spotify playcount observations; this endpoint reports saved worldwide aggregate daily streams across reporting services. Neither is a royalty statement. These reads do not start provider collection.
