---
title: 'Song creation availability'
description: 'Import songs into an owned catalog; standalone song creation is not available.'
---

Standalone `POST /api/songs` is not available. The API currently supports
[`GET /api/songs`](/api-reference/songs/songs) for reading songs.

## Add songs to a catalog

If you have an existing catalog you can access, use
[`POST /api/catalogs/songs`](/api-reference/songs/catalog-songs-add).
Each song needs its `catalog_id` and `isrc`; optional name, album, notes and
artist names supply fallback metadata. The API checks access to every named
catalog before processing songs. This writes song records and catalog links;
it is not a standalone create-only replacement.

## Unfinished product decision

[Reconciliation #327](https://github.com/recoupable/mono/issues/327) owns the
decision whether a separate song-creation API is needed and what ownership,
metadata-update and duplicate behavior it should allow. The old standalone
request and response are removed from the callable specification until that
decision and its implementation exist. Do not omit `catalog_id` or substitute
an unrelated catalog to make a write succeed.
