## Hosted workflows

`POST /api/content/create` retains the hosted preset workflow. Supply the authorized
`artist_account_id`, optional `template`, `images`, `songs`, `lipsync`, `upscale`
and `caption_length`. Discover templates through `/api/content/templates` and its
detail route. The response contains `runIds`; poll `/api/tasks/runs?runId=...` until
terminal. Report failures and inspect the final artifact before delivery.

Hosted lipsync is a supported preset intent. The coordinated API/worker repair
restores the selected song window to the fixed audio-to-video path; that repaired
journey is release-pending until deployment and actual output verification.

## Direct primitives

For images use `POST /api/content/image` with `prompt` and up to 10 unique
`image_urls`. The house model is Muse Image, switching to its edit path when
references are present. New clients must use `image_urls`; compatibility aliases
are translated by the reconciliation release.

For video use `POST /api/content/video` with `prompt`, optional `image_url` and
`end_image_url`, integer `duration` 5–15, and `resolution` `480P` or `768P`.
The house model is MiniMax H3 Max. It has no six-mode selector, arbitrary model,
reference-only, extend, `video_url` or `audio_url` request control. Unsupported
semantic inputs return 400 in the reconciliation release, before paid generation.

The dedicated `/api/content/lipsync` primitive restores the existing fixed LTX
model for the worker; it is not assumed available on an older deployment.
Caption, transcribe, analyze, upscale and edit have their own endpoint contracts.
Local ffmpeg composition can crop, trim, overlay or mux a song; it does not create
mouth synchronization or prove a hosted generation succeeded.

## Cost and evidence

Each generation/inference stage can consume credits. `/api/content/estimate`
returns an advisory estimate, not a guaranteed price or complete final ledger.
A later failed composition does not imply that completed upstream work was free.
On insufficient credits, surface `billingUrl` and stop. Consult [Credits](/credits).

Record image inspection, motion review and audio playback. The worker checks for
an audio stream on lipsync output before composition; perceptual mouth alignment
still requires inspection. No removed Stop hook enforces this QA.
