Let’s put Recoup to work.

This folder contains the Recoup customer plugin: skills and the MCP connection, together. Use the instructions for your app below.

Claude Code

Run these commands in Claude Code:

/plugin marketplace add recoupable/skills
/plugin install recoup-skills@recoup

Then open /mcp, select Recoup, and sign in with the email you used at checkout. The marketplace installs the current published release. For a local installation, the recoup-plugin folder includes the Claude manifest.

Codex

Use Codex’s local-plugin installation flow and select the recoup-plugin folder. Open the plugin’s Recoup connection and sign in with your checkout email.

Cursor

Use Cursor’s local-plugin installation flow and select the recoup-plugin folder. Its Cursor manifest and MCP configuration are included. Sign in to the Recoup connection with your checkout email.

Client installation controls can vary by version. Follow the official install guide if your app looks different. ChatGPT plugin distribution requires submission and review and is not included as an available installation option.
