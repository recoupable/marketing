# Historical email drafts

These files are preserved from the old GTM package for reference. They are not approved, current, or connected to a sender.

Feature descriptions, quantitative outcomes, testimonials, app links, timing promises, retention claims, and personalized statements have not been verified. The current data model cannot evaluate all draft triggers or populate all placeholders. Rewrite and review any useful idea against the current product before turning it into a campaign. Do not interpret these files as source evidence that an event happened or a feature shipped.
