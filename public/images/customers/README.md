# Customer logo assets

Source: `/Users/sidneyswift/Documents/Projects/Recoup/mono/marketing/design/logos/customers/`.

These are the existing customer logos requested by the user for the Quiet design. Original colors and proportions are preserved. The square SVG exports were rendered on white, trimmed to remove their empty canvas, and exported as 360px-wide WebP files for this white-background page.

The row identifies teams using Recoup. It does not claim a specific consulting engagement, financial outcome, or endorsement of a displayed demo. No private case-study information accompanies these logos.

The `-transparent.webp` variants are lossless, 720px-wide exports from the same original SVGs, rendered without flattening onto white and trimmed to their artwork bounds. The SVGs supply the original alpha masks for five logos. Seeker's embedded white-backed image uses an SVG color matrix with identity RGB and alpha `3 - R - G - B` (clamped to 0–1) before export: white becomes transparent while the solid dark lettering and orange mark remain opaque. Atlantic's colored rectangular artwork is part of its logo and is retained. The homepage uses these transparent variants with normal compositing, without CSS blend modes.
