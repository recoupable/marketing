# The AI Music Marketing Playbook


Recoup — Practical workflows for the work around the music.


## 01 / Choose the work worth improving

Start with a recurring task, a clear owner, and a useful result.

### Map the work before choosing a tool

List the work that repeats around an artist or release: research, content preparation, approval, distribution, outreach, and reporting. Record who does it, which information they need, and how long it takes.

Choose a first task with a repeatable input and an output someone can review. Drafting a release brief from approved materials is easier to assess than asking an agent to ‘grow the artist.’

### Tools, agents, and the full workflow

A tool helps with a step, such as drafting a caption. An agent can coordinate several steps when it has the right instructions, access, and integrations. Neither removes the need to decide what good work looks like.

Compare the complete cost: setup, software, usage, review, and maintenance. Measure the time saved on your own work instead of assuming an agent replaces every hour someone spends on the task.

## 02 / Build a repeatable content process

Create a batch, review it together, and use what you learn next time.

### Prepare the artist context

Collect an approved biography, music links, release details, audience notes, examples of the artist’s voice, and subjects to avoid. Keep these in one place so the next brief starts with the same context.

1. Choose the campaign goal and channels.

2. Ask for several angles and formats using the approved artist material.

3. Select the strongest ideas and check facts, voice, and rights.

4. Put approved work into your calendar or connected publishing tool.

5. Review results and use the findings in the next batch.

### Four prompts to start with

**Instagram carousel**

Create a 7-slide Instagram carousel for [ARTIST NAME] about [TOPIC]. Audience: [DEMOGRAPHIC]. Tone: [authentic/hype/vulnerable/educational]. Include a hook on slide 1, value on slides 2–6, and a CTA on slide 7. Reference recent track [SONG NAME]. Use only the facts in the attached artist brief.

**Short-form video**

Write a 30-second video script for [ARTIST NAME]. Hook in the first 3 seconds: [PATTERN INTERRUPT]. Middle: [STORY/REVEAL]. End: [CTA]. Include on-screen text suggestions. Separate the script from footage or music we still need permission to use.

**Release announcement**

Create 5 variations of a release announcement for [SONG/ALBUM NAME] by [ARTIST NAME], releasing on [DATE]. Try these angles: emotional, high-energy, behind-the-scenes, fan-focused, and teaser. Keep the date, title, and links exactly as supplied.

**Thread**

Write a 5-post thread from [ARTIST NAME]’s perspective about [TOPIC]. Start with a strong hook. Posts 2–4 should tell a story using the attached source material. The last post should direct readers to [LINK/ACTION]. Use first-person, conversational language.

### Improve the next batch

Look at which formats earned useful responses, what fans asked about, and which posts underperformed. Turn those findings into explicit changes to the next brief. Keep the artist’s judgment in the loop; engagement alone does not define their voice.

## 03 / Research the audience

Turn available audience information into a brief your team can act on.

### Start with information you can access

Bring together artist analytics, social reports, campaign results, and research on comparable artists. Access varies by platform and account; ask the agent to identify missing information rather than fill it with guesses.

- Where listeners and engaged fans are located.

- Which platforms and formats earn a response.

- Themes in comments, questions, and fan conversations.

- Comparable artists, relevant curators, and potential collaborators.

### Make the output useful

Ask for an audience brief with sources, observations, and proposed actions. Keep measured facts separate from hypotheses. A suggested audience to test is different from an audience you have already reached.

**Audience brief**

Using these reports, summarize our current audience and three opportunities to investigate. For each finding, cite its source and reporting period. Separate observed data from hypotheses. List the missing information that would change your recommendation.

## 04 / Plan the whole release

Organize pre-release, launch, and follow-up work around one calendar.

### Before release

Confirm the release date, approved artwork, credits, links, and campaign goal. Work backward to plan teasers, the announcement, press materials, creator briefs, and any pre-save campaign.

- Draft channel-specific content from the same release brief.

- Research relevant curators, publications, and collaborators.

- Prepare outreach for someone to review and send.

- Assign an owner and approval deadline to every deliverable.

### Release week

Check that the live links and release information are correct. Prepare launch posts, emails, and responses to common questions. Use the calendar to coordinate timing across the team.

Ask for a concise daily report on available campaign and listening data. Flag missing feeds or delayed reporting so the team understands what the report can actually show.

### After release

Keep useful promotion going with live clips, fan reactions you have permission to share, behind-the-scenes material, and new stories about the music. Review what worked before planning the next release.

Let observed results shape the cadence. A fixed posting schedule is a starting point to test, not a guarantee of growth.

## 05 / Manage work across a roster

Keep each artist’s context distinct while sharing useful methods.

### One method, different artist context

A shared workflow can serve several artists, but each needs their own approved information, voice, release calendar, permissions, and goals. Keep those boundaries clear when connecting accounts and files.

1. Review an overnight or weekly brief across the roster.

2. Open the items that need a decision or approval.

3. Review draft content in each artist’s context.

4. Assign opportunities and follow-up work to named owners.

5. Update the shared workflow when the team finds a better method.

### Connect the tools you already use

Distribution services, analytics tools, design apps, project trackers, and email platforms all have different access and integration options. Decide which system owns each record before connecting them.

Start with the handoff that causes the most repeated work. A dependable connection between two tools is more useful than a broad setup nobody can maintain.

## 06 / Put the catalog to work

Apply the same discipline to older releases, reporting, and label operations.

### Find useful starting points

- Catalog marketing: draft new campaign angles around existing music.

- Artist research: bring comparable releases and audience signals into a sourced brief.

- Reporting: prepare a consistent view of the data the team can access.

- Artist services: reuse approved research, content, and release methods across the roster.

### Expand after the first workflow works

Begin with a small set of artists or releases and a clear review process. Test the workflow with the people who will use it. Expand after you can repeat the result and understand the exceptions.

Track preparation time, corrections, and whether the team can run the workflow again. Use what you learn to decide which catalog or department to bring in next.

## 07 / Start with one useful build

Turn an idea into a small project the team can evaluate.

### Your first steps

1. Choose a recurring task and the person responsible for it.

2. Collect the inputs and one example of an acceptable output.

3. Write down the checks the reviewer will make.

4. Run the workflow on a small set of real tasks.

5. Compare the result, review effort, and time with the current process.

6. Document how to run it, then decide what to improve or expand.
