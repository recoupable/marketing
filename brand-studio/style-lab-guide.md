# Recoup Style Lab

These are proposals for visual review. Keep the background material, palette arrangement, illustration, and type as independent choices.

## Compare before combining

1. **Backgrounds:** compare fine grain, diffused glass, and airbrush. For each material compare blue leading, lime leading, reversed direction, and inverted colors. No graphic or type is included.
2. **Illustrations:** compare ink, cut paper, airbrush, and frosted glass on a neutral background. Both the record and book are repeated across styles so the subject does not determine the choice.
3. **Typography:** compare five treatments of the same headline on identical artwork. Text remains editable.
4. **Mix:** choose a background, color arrangement, illustration, and type style. Save a draft combination or copy its full recipe.

## What inversion means

- Blue leads: approximately 70% blue, 30% lime.
- Lime leads: the same arrangement, but approximately 70% lime, 30% blue.
- Reverse direction: keep blue dominant and move the lime light to the opposite corner.
- Invert colors: an experimental orange/violet palette. RGB inversion of the anchors gives #007EBD → #FF8142 and #D6FF62 → #29009D. The generated study uses these inverted endpoints; it is not a pixel-for-pixel inversion of another image.

Article: [TITLE]
Argument: [ONE SPECIFIC POINT]

Color arrangement: [BLUE LEADS / LIME LEADS / REVERSED / INVERTED]
Illustration medium: [INK / CUT PAPER / AIRBRUSH / FROSTED GLASS]
Subject: [AN OBJECT OR ACTION THAT EXPRESSES THIS ARTICLE]
Type treatment: [SELECTED STYLE]
Exact headline: [APPROVED WORDING]
Recent six covers: [SUBJECT, MEDIUM, PALETTE, COMPOSITION]

Generate a text-free background and a separate illustration on a genuinely transparent background. Use the selected study images as material and color references. Keep one subject clear at thumbnail size. Do not reuse the same object for unrelated articles. Compose with editable DM Sans typography and generous margins. Check the entire headline for contrast and keep it separate from the subject. Change only one ingredient when comparing directions; vary at least two meaningful ingredients across different articles. Use supplied evidence for factual diagrams or product content.

The mixer’s Copy recipe button includes the selected image prompts and local reference paths. Upload the referenced images to the image tool when using that recipe elsewhere. Backgrounds and transparent illustrations can be downloaded separately from the comparison panels. Browser previews are live compositions; they are not flattened export files.
